# Changelog

Усі важливі зміни проєкту фіксуються в цьому файлі.
Формат базується на [Keep a Changelog](https://keepachangelog.com/uk/1.0.0/).
Версії — [SemVer](https://semver.org/) (v1.0, v1.1, v1.2, ...).

Кожен запис нижче містить: версію, дату, автора та опис змін.
Записи у розділі "Автозапис комітів" додаються автоматично git-хуком
(`.githooks/post-commit`) при кожному коміті.

## [v1.0-production] - 2026-06-14
### Опубліковано
- Перший публічний реліз сайту атестації.
- Сайт опубліковано на Netlify: https://atestaciya-yabko.netlify.app/

## [v1.1] - 2026-06-14
### Додано
- Картки на дашборді: кількість співробітників з підвищенням, пониженням
  та підтвердженням посади за результатами атестації.
- Відображення дати/часу останнього оновлення даних у топбарі.

## [v1.0] - 2026-06-14
### Додано
- Початкова версія дашборду атестації (дашборд, команди, загальна таблиця,
  тести, КЯ, чати, вхідні дзвінки, замовлення, КПІ, відгуки, план).
- Графіки на Chart.js, фільтри, сортування таблиць, пагінація.
- Імпорт оновлених даних з `.xlsx`/`.xls` із порівнянням змін.
- Експорт відфільтрованої таблиці у CSV.
- Інструкція з публікації (`DEPLOY.md`) для GitHub Pages, Netlify, Vercel.
- Налаштовано Git-репозиторій, `.gitignore`, `README.md`, `CHANGELOG.md`.
